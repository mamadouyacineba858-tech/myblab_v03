# A10-DISP2 - Winstar WH1602B

16x2 character LCD module asset (asset-only, no implementation).

- Manufacturer/reference: Winstar Display WH1602B-TFH-JT#
- Controller ST7066U, 6800 parallel interface (4-bit / 8-bit), 5x8 dots
- Module 80.0 x 36.0 x 13.5 mm; view area 66.0 x 16.0 mm; active area 56.2 x 11.5 mm
- 1x16 PTH header, 2.54 mm pitch
- Runtime raster (CSA RUNTIME-V2): 378x170 px; 3x: 1134x510 px; 16 header pads, complete board edges
- Electrical geometry is normalized from the manufacturer drawing: 2.54 mm => 12 px; contacts (12,12) .. (192,12), span 180 px, electrical width 204 px (FINAL LOCK).
- Contacts are NOT pixel-probed from any raster.
- Pin map: 1=VSS, 2=VDD, 3=VO, 4=RS, 5=R/W, 6=E, 7=DB0, 8=DB1, 9=DB2, 10=DB3, 11=DB4, 12=DB5, 13=DB6, 14=DB7, 15=A, 16=K.
- Founder reference is the historical Founder PASS sheet, kept bit-identical. Its top view (13 pads) and pins close-up panel (17 pads, DB3 duplicated) are non-authoritative.
- RUNTIME-DERIVATIVE-V1 was rejected and is not shipped.
- No implementation/code authorization is implied by this pack.
